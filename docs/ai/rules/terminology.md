# Terminologia

| Usar | Não usar | Significado |
|------|----------|-------------|
| **UI** | FE, frontend (em docs/planos) | SPA React (`sistema.isaque.it`, `cliente.isaque.it`, admin notify) |
| **API** | backend (quando for o Nest de faturas) | `api.isaque.it` |
| **Notify** | notifier, mailer (como nome de repo) | `notify.it` — carteiro |
| **Barcode** | barcodes (legado) | `barcode.it` |

| Termo | Contexto |
|-------|----------|
| SPA | Build estático em produção (sem porta Node) |
| Master | `nivel = 10` em `id_pessoas` |
| Path público notify | `https://api.isaque.it/notify.it/` (ou `/notify/` conforme Apache) |
| Path público barcode | `https://api.isaque.it/barcode.it` |
